# Review Checklist
Use this checklist as a quick reference when reviewing a pull request.

> [!NOTE]
> Not every item will apply to every review.

## Changes
- [ ] I understand the purpose of this pull request.
- [ ] The changes are focused on a single purpose.
- [ ] The changes are clear and easy to follow.

## Quality
- [ ] The changes appear to work as intended.
- [ ] I did not notice obvious errors or missing updates.

## Feedback
- [ ] My feedback is respectful and constructive.
- [ ] I explained my suggestions when appropriate.
- [ ] I acknowledged good work where appropriate.
