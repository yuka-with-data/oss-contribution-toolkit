# AI-Assisted Workflow Example

This example shows how AI can assist with an open source contribution while the contributor remains responsible for the final result.

## Example Workflow

The contributor uses AI to:

- Understand an issue or unfamiliar code
- Brainstorm possible solutions
- Draft documentation or a pull request description
- Improve writing and grammar

Before submitting, the contributor:

- Reviews all AI-generated content
- Verifies technical accuracy
- Tests any code changes
- Follows the project's contribution guidelines

## Good Practices

- Treat AI as a helper, not a replacement for review
- Treat AI as an editor, not a writer
- Be transparent if the project requests AI disclosure
- Take ownership of the final contribution

Responsible AI use can improve productivity while maintain the quality and integrity of open source contributions.
