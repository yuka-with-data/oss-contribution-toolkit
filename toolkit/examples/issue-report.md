# Issue Report Example

This example shows how to write a clear and actionable issue report.

## Example Issue

**Title:** Broken link in installation guide

**Description:**
> The installation guide link in the `README.md` returns a 404 page. Updating it to the current documentation URL would help new contributors.

## Before Submitting

The contributor:

- Searches for existing issues.
- Confirms the problem still exists.
- Provides enough detail to reproduce or understand the issue.
- Keeps the report focused on one topic.

## What Makes This a Good Issue Report?

- Clear and descriptive
- Easy to understand
- Includes relevant details
- Helps maintainers identify and resolve the issue more efficiently

A well-written issue report makes it easier for contributors and maintainers to collaborate on improving the project.
