# First Pull Request Example

This example shows what a simple first pull request might look like.

## Example Changes

**Title:** Fix typo in installation guide

**Summary:**
> This PR fixes a typo in the installation guide by correcting the package name in the setup instructions. No other changes were made.

## Before Opening the PR

The contributor:

- Search for similar or identical pull requests
- Tests or reviews the change
- Keeps the PR focused on a single issue
- Writes a clear title and description
- Links the related issue, if applicable

## After Opening the PR

The contributor:

- Responds politely to review feedback
- Makes requested updates when appropriate
- Waits patiently for the review process

## What Makes a Good First PR?

- Small and easy to review
- Clearly explains the change
- Stays focused on one improvement
- Makes collaboration easier for maintainers
