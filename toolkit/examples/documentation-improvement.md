# Documentation Improvement Example
This example shows a simple documentation contribution that improves clarity without changing the project's functionality. 

## Example Change
**Title:** Clarify installation instructions in `README.md`

**Summary:**
> This update adds a missing prerequisite and clarifies the installation steps for new contributors. No code changes are included.

## Before Submitting
The contributor:
- Confirms the documentation is accurate
- Reviews the formatting and links
- Keeps the changes focused on a single improvement
- Previews the rendered Markdown, if possible

## Why This Is a Good Documentation Contribution
- Improves the contributor experience
- Easy to review and verify
- Does not change the project's behavior
- Helps keep the documentation clear and up to date

Documentation improvements, even small ones, are valuable contributions to open source projects.
