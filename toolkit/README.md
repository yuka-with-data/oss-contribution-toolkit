# Toolkit
The `toolkit/` directory contains practical resources that support the open source contribution workflow. These materials are designed to complement the guides in the `playbook/` by providing reusable references, templates, and examples. 

## Contents
- **principles/** – Core concepts and best practices for contributing to open source.
- **templates/** – Ready-to-use templates for pull requests, issues, and reviews.
- **examples/** – Lightweight examples of common contribution scenarios.
- **utilities/** – Practical references and workflows to assist contributors.

Use these resources as references throughout your open source journey. They are intended to be concise, reusable, and easy to adapt across different projects.
