# AI-Assited Contributions

## Why This Matters

AI tools are becoming a normal part of open source workflows. Contributors use them to understand codebases, investigate issues, draft documentation, generate code, and review changes.

While the tools continue to evolve, one principle remains unchanged:
> Contributors are responsible for the work they submit.

## AI as an Assistant, Not a Replacement

AI can help you understand unfamiliar code, explain errors and test failures, draft documentation, etc. AI can help you accelerate learning and development, but generated suggestions should always be reviewed and validated.

## AI in the Contribution Workflow

Today, many contributors use AI to investigate failed CI checks, linting errors, or test failures.

When troubleshooting CI, make sure to:

1. Read the CI logs first
2. You could use AI, such as Copilot which is already implemented in GitHub workflow, to help interpret the error and suggest possible solutions.
3. Verify the proposed fix.
4. Re-run tests when possible.
5. Confirm the CI checks pass after making changes.

> Do not assume the first AI-generated explanation is always correct.
