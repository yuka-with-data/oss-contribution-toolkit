# Open Source Contribution Learning Resources

This directory contains curated resources for learning Git, GitHub, and open source contribution workflows.

## Git & GitHub Fundamentals

- **Git Documentation** – Official Git documentation and references for learning Git workflows.  
  <https://git-scm.com/doc>

- **Pro Git Book** – A free, comprehensive book covering Git concepts and workflows.  
  <https://git-scm.com/book/en/v2>

- **GitHub Docs** – Official documentation for GitHub features, collaboration workflows, issues, and pull requests.  
  <https://docs.github.com/>

- **Git Cheat Sheet** – A quick reference for commonly used Git commands and workflows.  
  <https://git-scm.com/cheat-sheet>

## Beginner-Friendly Open Source Guides

- **GitHub: First OSS Contribution Guide** – Step-by-step instructions for making your first open source contribution.  
  <https://github.com/readme/guides/first-oss-contribution>

- **GitHub Docs: Finding Ways to Contribute** – Guidance on choosing projects, finding issues, and contributing code or non-code improvements.  
  <https://docs.github.com/en/get-started/exploring-projects-on-github/finding-ways-to-contribute-to-open-source-on-github>

- **Open Source Guides: How to Contribute** – A comprehensive guide covering why and how to contribute to open source projects.  
  <https://opensource.guide/how-to-contribute/>

## Interactive Learning

- **First Contributions** – A beginner-friendly project that walks through making your first pull request.  
  <https://firstcontributions.github.io/>

- **GitHub Education: Intro to Open Source** – Learning experience covering project discovery, workflows, and community basics.  
  <https://education.github.com/experiences/intro_to_open_source>

## Finding Projects & Issues

- **GitHub Issue Search** – Learn how to use filters and labels to find contribution opportunities.  
  <https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests>

- **goodfirstissue.dev** – Discover beginner-friendly open source issues across projects.  
  <https://goodfirstissue.dev/>

## Articles & Case Studies

- **How I contributed a new model to the Transformers library using Codex** – A real-world example of using AI-assisted workflows for an open source contribution.  
  <https://huggingface.co/blog/nielsr/contributing-to-transformers-with-codex>

## Suggested Learning Path

1. Learn basic Git and GitHub workflows.
2. Follow a first contribution guide.
3. Explore beginner-friendly issues and projects.
4. Practice making a small pull request.
5. Learn from real-world contribution stories.
